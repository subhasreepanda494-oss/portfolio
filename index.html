Data Analytics & Python Project

ESG Carbon Compliance Copilot

Overview

A data-driven application engineered to track, analyze, and visualize corporate ESG carbon-emission metrics with GHG Protocol compliance reporting and audit logging.

Problem

Organizations struggle to aggregate fragmented utility and operational emissions data, verify compliance against greenhouse gas emission factors, and maintain audit-ready documentation without costly manual overhead.

Solution

Built an end-to-end analytics platform powered by Python and FastAPI that automatically classifies uploaded activity data into GHG scopes (Scope 1, Scope 2, Scope 3), calculates deterministic CO₂e values against verified emission factors, detects greenwashing risks, and logs an immutable audit trail.

Tech Stack

Python FastAPI Data Analytics Pandas ESG Metrics Render

Key Features

  • Emissions Tracking: Automated Scope 1, Scope 2, and Scope 3 classification using UK Government GHG conversion factors.
  • Data Processing: Ingestion and structured preprocessing of utility CSVs and sustainability documents.
  • Audit-Ready Analytics: Real-time compliance calculation with transparent conversion factors and verification trails.
